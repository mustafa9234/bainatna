# بيناتنا — Flutter starter

نموذج أولي لواجهة أندرويد عربية بدون تسجيل حساب.

## الموجود حالياً
- واجهة عربية باتجاه RTL وهوية بنفسجية/وردية ولمسات ذهبية.
- شاشة أولية لإنشاء رمز من 6 أرقام أو إدخال رمز.
- شاشة مشاعر مع صياغة تختلف حسب المرسل (أنا / هي).
- معاينة محلية للعبارات.

## ما لم يُنفّذ بعد
- رمز الربط حالياً تجريبي ومحلي، ولا يربط جهازين فعلياً.
- لا توجد قاعدة بيانات أو مزامنة إنترنت أو حماية خلفية للرموز بعد.
- لا توجد رسوم ثلاثية الأبعاد للقبلة والحضن بعد.
- لم يُبنَ APK ولم يُختبر على هاتف؛ بيئة إعداد هذه الملفات لا تحتوي Flutter SDK.

## البناء بعد تثبيت Flutter
1. ثبّت Flutter SDK و Android Studio.
2. من مجلد المشروع نفّذ: `flutter pub get`
3. نفّذ: `flutter run` للتجربة أو `flutter build apk --release` لبناء APK.

المرحلة التالية للتطوير: إضافة Firebase Anonymous Authentication بمعرّف مجهول للجهاز، ثم آلية pairing آمنة بقواعد صلاحيات تمنع أي طرف ثالث من قراءة المحادثة، وبعدها مزامنة المشاعر والتفاعلات.
